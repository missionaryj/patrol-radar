Help

Not seeing police on the map?

Sometimes police gear doesn't show up. A short recording helps fix that. Here's how to send one:

  1. Scan. Use the Android app if you can, and set Android app scan mode to Fastest (Settings → Scanning). Tap Scan.
  2. Record. When you're near police, pull up the Live detections panel and tap ● Record.
  3. Keep recording a few minutes while you stay nearby (only when it's safe).
  4. Tap ■ Stop rec. Android app: tap Share file, pick Gmail (or any email app), send it to percolatorbiz@gmail.com and add a short note: what you saw and roughly when. Done.
  5. Web: tap Export to save the patrol-radar-session-….json file, then tap Email the debug file below and attach the exported file.
✉️ Email the debug file Sends to percolatorbiz@gmail.com from your own email app. On the web the file can't be attached automatically, so attach it yourself. What's in the file: only police-gear matches (other devices are dropped), device IDs that are scrambled and change every session, ~150 m map areas (never your exact location), signal strength and times, the matched signal data with serial-like text masked, and scan-health counts. No MAC addresses, device names or Wi-Fi network names. A Wi-Fi row is one access point when the phone can tell them apart, and only the signature name when it cannot. It is not one vehicle. "Vehicle arrived" and "Vehicle left" are times you mark yourself.

Privacy

  • Receive-only: never connects, pairs or writes to a device.
  • Device IDs are salted hashes that change every session.
  • Saved locations are ~200 m areas; your exact spot stays on screen only.
